Quick guide
  1. Create a Skill or import one SKILL.md file.
  2. Edit the name, task and Markdown. Save a revision.
  3. Prepare a request in ChatGPT collaboration.
  4. Copy the prompt into your own ChatGPT conversation.
  5. Paste the JSON response here. Review the diff and complete proposed Skill.
  6. Apply the response, then run checks and export.
Requests are bound to a saved revision. After editing the project, create a new request. Local imports do not include supporting scripts or attachments.
