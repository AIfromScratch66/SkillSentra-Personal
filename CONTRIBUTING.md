# Contributing

Keep this branch focused on personal Skill authoring and explicit ChatGPT review. Use English in source comments, interface text, documentation and tests.

Run the Python and browser suites before proposing changes. Cover stale context, explicit acceptance, literal imported content, version history and removed-route behavior when relevant. Use synthetic fixtures and never submit real user databases, prompts or credentials.

Submit public repository changes against `main`. Keep the private baseline separate. Do not reintroduce marketplace, payment, team administration or automatic external message submission without an explicit scope decision.
