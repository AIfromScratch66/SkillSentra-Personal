# Security

SkillSentra Personal is a local Developer Preview for one user on a trusted computer. Do not expose it through a reverse proxy, tunnel or public interface. It does not authenticate other local processes.

Only allowlisted static assets are served. Imported Markdown and responses remain text. The app rejects foreign browser origins, unexpected Host headers and stale writes. These controls are bounded protections, not an independent security audit.

A private vulnerability reporting channel has not yet been announced. Do not post secrets, real project data or exploit details in a public issue. Public distribution remains pending security and ownership review.
